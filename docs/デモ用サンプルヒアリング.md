# デモ用サンプルヒアリング（架空: ひかり工務店）

商談・社内デモでそのまま使えるサンプル一式です。**すべて架空の会社・架空の連絡先**です。

**この題材にしている理由**: (1) プリセット外業種なので「AI業種判定→言葉づかい自動調整」が動く様子を見せられる、(2) AIデザイン提案で「クラフト・実直」が推されやすく新デザインの見せ場になる、(3) 写真のフリー素材が豊富。

---

## デモの流れ（おすすめ）

1. 案件一覧 →「＋新しいサイトを作る」（案件名: ひかり工務店さま（デモ） など）
2. Step1の「打ち合わせメモから自動入力」に下のメモを**そのまま貼り付け** →「AIで下書きを作成」
   - AIがフォームを埋めていく様子が最初の見せ場
3. 埋まらない項目（後述）を手で補完 →「確定して次へ」
4. Step2: 業種判定「工務店」＋AIの言葉づかい調整の表示 → **「AIデザイン提案」→「提案してもらう」**（3案・根拠付き）→ 1案選んで確定
5. Step3: 生成開始 → **ライブ建設ビュー**（右の大画面でサイトが実物のまま組み上がっていく。約5分のショー）
6. Step4: 写真アップロード → Step5 → Step6 チェック実行 → 承認 → Step7 公開

## メモから埋まらない/手動確認する項目

| 項目 | 対応 |
|---|---|
| F. 参考サイトURL（必須） | AIは創作しないので空欄になる。好きな工務店サイトを1件貼る（例: `https://www.muji.net/ie/`） |
| F. メインカラー | `#2d5a3d`（深緑）を指定すると世界観が揃う |
| C. 検索語 / G. ポジショニング | AIの提案が入るので内容確認だけでOK |
| G. Googleビジネスプロフィール | 架空の会社なのでチェックなし・URL空欄のままでOK（実案件では登録済みならチェック＋URL。未登録なら公開後の登録をおすすめすると喜ばれる） |

## 用意するフリー素材（3枚）

写真AC・Unsplash・Pexels などで。ロゴは無くてOK（社名テキスト表示になる）。

| スロット | 内容 | 仕様 | 検索キーワード例 |
|---|---|---|---|
| メインビジュアル | 木造住宅の建築現場か、木の温もりのあるリビング | **横長・幅1920px以上** | 工務店 施工 / 木造 建築現場 / 注文住宅 リビング 木 |
| 代表者の写真 | 50〜60代くらいの男性職人・棟梁風ポートレート | 800px以上 | 大工 職人 ポートレート / 作業着 男性 笑顔 |
| 事務所・店舗 | 小さな事務所や店舗の外観 | 1200px以上 | 工務店 外観 / 事務所 外観 小規模 |

※ メインビジュアルはGemini課金設定後なら Step4「AIで生成」でその場生成も可（デモ映えする）。
※ 代表者・事務所の写真は実案件では実物のみ（AI生成不可）。デモではフリー素材で代用。

## デモ後の片付け

公開まで見せた場合: Step7で「サイトを非公開にする」（承認者のみ）→ 案件一覧の「削除」は公開前の案件のみ可能なので、公開済みデモの完全削除はシステム管理者に依頼。公開前で止めた場合は一覧の「削除」だけでOK。
